မြန်မာ SRT ဘာသာပြန်စနစ်

SRT ဖိုင်တင်ပါ၊ ဘာသာပြန်မယ့်အချိန်အပိုင်းအခြားကို ရွေးပါ။ မီလီစက္ကန့်အထိ သတ်မှတ်နိုင်ပြီး ထုတ်ယူမယ့် SRT ရဲ့ အချိန်ကို မူရင်းအတိုင်းထားနိုင်သလို 00:00:00,000 ကနေ ပြန်စနိုင်ပါတယ်။

၁။ ဖိုင်နဲ့ Worker သတ်မှတ်ရန်

Worker URL ကို တစ်ကြိမ်ထည့်ပြီး နောက်တစ်ကြိမ်လည်း အသုံးပြုနိုင်ပါတယ်။ API Key ကို ဒီစာမျက်နှာမှာ မထည့်ပါနဲ့။

၂။ ဘယ်အချိန်ကနေ ဘယ်အချိန်အထိ ဘာသာပြန်မလဲ
